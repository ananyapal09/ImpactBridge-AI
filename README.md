# 🚀 ImpactBridge AI

An AI-powered NGO Management and Donation Platform built using the MERN Stack and Python.

---

## 📌 Problem Statement

Traditional donation platforms lack transparency. Donors often don't know where their money goes, while NGOs struggle to build trust.

ImpactBridge AI solves this through real-time donation tracking, AI-powered NGO recommendations, trust scoring, and intelligent impact reports.

---
